## Assignment 5

## Implemented features

1. **DOM manipulation and styling:** Day/Night theme toggle, background color cycling, dynamic text, and a Read More section.
2. **Attribute manipulation:** Clicking a gallery thumbnail updates the `src` and `alt` of a larger preview image. The preview can be closed with its close button, the backdrop, or Escape.
3. **Event handling:** Click listeners for buttons, a live-time button, keyboard navigation through the main menu with arrow keys/Home/End, and Escape handling for overlays.
4. **Callbacks and switch:** A greeting language selector uses a `switch` statement for English, Russian, and Kazakh.
5. **Objects, arrays, loops and higher-order functions:** Cafe tips are stored as an array of objects, transformed with `map()`, and added with `forEach()`.
6. **Sound:** A short notification sound is generated through the Web Audio API after the user clicks the sound button.
7. **Animation:** CSS animation is triggered by a button and by expanding the Read More section.
8. **Previous Assignment 4 features retained:** Contact form validation, password length counter, FAQ accordion, subscription popup, background color control, date/time footer, and 3×3 image gallery.

## How to test

- Open `index.html` in a browser.
- Click gallery images to open the large preview; close it with the X, by clicking outside the image, or with Escape.
- Use **Switch Day / Night** and **Change background color**.
- Click **Show current time**.
- Change the greeting language.
- Click **Play notification sound** and **Animate this section**.
- Click **Read more** to reveal additional cafe details and tips.
- Use Left/Right arrow keys while a main navigation link is focused; Home and End move to the first and last link.
- Check the FAQ accordion, subscription popup and contact form on the existing pages.
